SkillSwap
Peer-to-peer skill exchange for students

🌐 Live Demo


🎯 Problem
Students have skills they can teach but struggle to
find people who can teach them what they want to learn.

💡 Solution
SkillSwap connects students based on what they can
teach and what they want to learn.

✨ Features
• Skill-based discovery
• Student profiles
• Matching
• AI assistance
• Secure OTP authentication


🛠️ Tech Stack
React
TypeScript
Express
